# Bomber3D

**Bomber3D** — это 3D-игра в жанре «Bomberman» с видом сверху. Игроку предстоит пробиваться через клеточное поле, заставленное разрушаемыми блоками, уничтожать врагов с помощью бомб и находить выход на противоположной стороне. Проект написан на Unity и демонстрирует классическую механику с современными настройками сложности.

---

## 🧠 Суть игры

Вы управляете персонажем, который перемещается по сетке из клеток. Ваша главная задача — добраться до **зелёного портала (выхода)**, расположенного в правой верхней части карты. Однако путь преграждают:

- **Разрушаемые блоки** — их можно взорвать бомбой, чтобы открыть проход.
- **Враги** — они патрулируют поле и двигаются в вашу сторону. При столкновении игра заканчивается.

Чтобы победить, нужно:

1. Ставить **бомбы** (клавиша `Space`) в той клетке, где вы стоите.
2. Бомба взрывается через несколько секунд, создавая **крестообразный взрыв** (вверх, вниз, влево, вправо) на заданный радиус.
3. Взрыв уничтожает все разрушаемые блоки и всех врагов, попавших в зону поражения.
4. После зачистки пути вы добираетесь до выхода — уровень пройден.

Враги **респавнятся** с определённым интервалом, поэтому нужно действовать быстро и стратегически: расставлять бомбы так, чтобы задеть сразу несколько противников, и не попасть в собственный взрыв.

## 🎮 Управление

### В игре (сцена Main)
| Клавиша | Действие |
|---------|----------|
| `WASD` | Движение по сетке (шаг за шагом, привязано к клеткам) |
| `Space` | Поставить бомбу в текущей клетке (если там ещё нет бомбы) |
| `Esc` | Пауза / возобновление игры |

### В меню настроек
На панели настроек доступны ползунки, которые позволяют гибко менять сложность прямо во время игры:

- **Player Speed** (клеток/с) — скорость передвижения игрока.
- **Enemy Speed** (клеток/с) — скорость передвижения врагов.
- **Bomb Radius** (клетки) — радиус взрыва бомбы (влияет на зону поражения).
- **Enemy Spawn Interval** (с) — интервал между появлениями новых врагов.

Эти параметры дают возможность подстроить игру под свой стиль — от спокойного прохождения до динамичного экшена.

## 🚀 Запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/LordPelmeha/SimpleBomber.git
   ```
2. Откройте проект в **Unity** (рекомендуется версия 2021.3 или новее).
3. Откройте сцену `Main` (находится в `Assets/`).
4. Нажмите **Play** и начинайте игру.

## 🧩 Особенности реализации

- **Клеточная механика** — движение и расстановка бомб строго по сетке, что обеспечивает тактическую точность.
- **Динамический спавн врагов** — противники появляются через заданные интервалы, создавая постоянное напряжение.
- **Настраиваемая сложность** — все ключевые параметры регулируются в реальном времени через UI.
- **Пауза** — можно остановить игру в любой момент, чтобы оценить обстановку.
- **Визуальные эффекты** — взрывы сопровождаются анимацией и частицами (реализовано через шейдеры).
